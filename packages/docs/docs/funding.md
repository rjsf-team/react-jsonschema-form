# Sponsoring RJSF

react-jsonschema-form is free and open source. Its maintainers use agentic coding tools to triage issues, review pull requests and ship fixes, and those tools have real monthly costs.

If RJSF saves you or your team time, please consider sponsoring the project on [Open Collective](https://opencollective.com/react-jsonschema-form).
Contributions of any size help cover those costs and keep releases coming.

Every published `@rjsf/*` package lists this collective in its `funding` field, so `npm fund` in your project shows it alongside your other dependencies.

Not able to sponsor? [Contributing](./contributing.md) code, docs, bug reports or reviews helps just as much.
