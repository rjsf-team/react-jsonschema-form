v7 makes `Form` a function component that owns its data, decides where each field's label, help and errors go, and ships as ESM only. Pick your theme and validator, and tick what your code and schemas use, to see the changes that apply to you in the order to apply them. Agents can start from [llms.txt](pathname:///migration-guides/v7/llms.txt), which lists every entry with a link to its Markdown.

For the features v7 adds, see [What's new in v7](./whats-new-v7.md).
