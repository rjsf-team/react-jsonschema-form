v7 makes `Form` a function component that owns its data, decides where each field's label, help and errors go, and ships as ESM only. Every change is listed below, grouped by what it touches in your app, in the order to work through them.

Everything in the filter bar and under More filters starts selected, so every change shows. Pick your theme or Core only, and deselect what your app doesn't customize and the code and schema features it doesn't use, to hide the changes that can't affect you.

For the features v7 adds, see [What's new in v7](./whats-new-v7.md). Agents can start from [llms.txt](pathname:///migration-guides/v7/llms.txt), which lists every entry with a link to its Markdown.
