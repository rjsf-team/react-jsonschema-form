v7 makes `Form` a function component that owns its data, decides where each field's label, help and errors go, and ships as ESM only. Every change is listed below, grouped by what it touches in your app, in the order to work through them. Answering the questions is optional; it only hides changes that can't affect you. Agents can start from [llms.txt](pathname:///migration-guides/v7/llms.txt), which lists every entry with a link to its Markdown.

For the features v7 adds, see [What's new in v7](./whats-new-v7.md).
