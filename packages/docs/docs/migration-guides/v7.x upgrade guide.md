### Node support

Version 7 supports only the active Node.js LTS lines: `^22.18.0 || ^24.11.0 || >=26.0.0`.
Node 20, Node 23, Node 25, and Node 24 releases before 24.11.0 are no longer supported, as they are not [maintained versions](https://nodejs.org/en/about/releases/).
Node 22.18.0 is the floor because it is the first release to enable native TypeScript type stripping by default.

All PR and branch builds are running against Node 22, 24 and 26

Dropping Node 20 also let us upgrade `pnpm` past version 10, which had been pinned because pnpm 11+ requires Node >=22.13. We're now on the latest pnpm release (12).

### React version

RJSF is no longer actively supporting React version < 19.x.
React 19 is officially supported on all the themes.
