## About The Project

## Getting Started

### Prerequisites

- `@rjsf/core >= 6`
- `@rjsf/utils >= 6`
- `@rjsf/validator-ajv8 >= 6`

```bash
yarn add @rjsf/core @rjsf/utils @rjsf/validator-ajv8
```

### Installation

```bash
yarn add @rjsf/shadcn
```

## Usage

```js
import Form from '@rjsf/shadcn';
```

or

```js
import {withTheme} from '@rjsf/core';
import {Theme as shadcnTheme} from '@rjsf/shadcn';

const Form = withTheme(shadcnTheme);
```

## Theming

`@rjsf/shadcn` ships no stylesheet. Like shadcn itself, it is styled by your application's Tailwind build and by the
CSS variables your application defines, so the form picks up your colors, radius, fonts and dark mode automatically.

### Tailwind

Set up Tailwind v4 and shadcn in your application by following the
[shadcn installation guide](https://ui.shadcn.com/docs/installation), then tell Tailwind to scan this package for
class names by adding a `@source` line to the CSS file that imports Tailwind:

```css
@import "tailwindcss";
@source "../node_modules/@rjsf/shadcn/lib";
```

Tailwind skips `node_modules` unless a path is opted in explicitly. The path is relative to the CSS file, so adjust
it to where that file lives. With pnpm the package may be a symlink into the store; if the classes do not appear,
point `@source` at the resolved path or use `@tailwindcss/vite`, which follows the symlink.

### CSS variables

The components use the standard shadcn variables — `--background`, `--foreground`, `--primary`,
`--primary-foreground`, `--secondary`, `--muted`, `--accent`, `--destructive`, `--border`, `--input`, `--ring`,
`--radius` and their `-foreground` counterparts — through the `@theme inline` mapping that `shadcn init` writes into
your global CSS. Any theme generated by [shadcn themes](https://ui.shadcn.com/themes) or
[tweakcn](https://tweakcn.com/editor/theme) works as is; the
[playground](https://rjsf-team.github.io/react-jsonschema-form/) demonstrates several.

## RTL

### Installation

```bash
npm install @radix-ui/react-direction --save
```

### Implementation

1. Wrap your layout with DirectionProvider:

    ```tsx
    import {DirectionProvider as RadixDirectionProvider} from '@radix-ui/react-direction;
    
    function Layout({children, direction}) {
        return (
            <RadixDirectionProvider dir={direction}>
                {children}
            </RadixDirectionProvider>
        );
    }
    ```

2. Set HTML direction attribute:

    ```html
    <html dir="rtl" lang="en">
    ```

3. You can refer to `direction-context.tsx`, `direction-provider.tsx` and `rtl-toggle.tsx` from demo repository for
   implementation.

## Updating to latest shadCN version

- Simply copy the shadcn components into shadcn/src/components/ui and rebuilt the packages or using the shadcn CLI at
  the root level with the components.json
- For RTL version, you might need component from [here](https://github.com/shadcn-ui/ui/pull/1638)
  by [nahasco](https://github.com/nahasco)
- [Fancy multi-select](https://craft.mxkaske.dev/post/fancy-multi-select)
